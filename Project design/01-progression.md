# Прогрессия и "потолки статуса" — дизайн-нотатки

Контекст: торговля — центральная механика, всё остальное (бой, ивенты, репутация, флот) —
поддержка среднего уровня глубины. Открытая песочница без жёсткой победы, вместо неё —
несколько независимых "потолков статуса", каждый даёт ощущение "я стал тем, кем хотел".
Игрок не обязан закрыть все три — можно годами гонять один торговый маршрут и быть довольным.

## Три потолка статуса (параллельные, не взаимоисключающие)

### 1. Богатство — "Купеческий барон"
Метрика: golото + рыночная стоимость груза на руках + сумма всего добра в Property (по всем
складам), одним числом.

Пороги (относительно стартового капитала `G0`):
- **Мещанин**: `< 10 × G0` — стадия 1, всё ещё выживание.
- **Купец**: `10-50 × G0` — стадия 2, warehouse уже окупает себя.
- **Магнат**: `50-200 × G0` — стадия 3-4, флот уже осмысленен.
- **Барон** (потолок): `> 200 × G0` — статус, не хардкап; после него рост замедляется
  естественно (некуда особо тратить), это и есть сигнал "ты добрался".

Подставь реальный `G0` из текущего стартового баланса — я не знаю точное число.

### 2. Влияние — "Некоронованный король Карибов"
Метрика: репутация одновременно у нескольких фракций.
Это самый интересный потолок именно из-за конфликта интересов: фракции конкурируют между
собой (Испания/Англия/Франция/Голландия), так что держать высокую репутацию у всех сразу —
не гринд, а балансирование (продавать испанские товары в английских портах вредит репутации
с испанцами и т.д. — стоит явно вписать такие противоречия в M14).

Порог: репутация `≥ +50` у **минимум 3 из 4** фракций одновременно. Не 4 из 4 — сделать это
специально труднодостижимым/несовместимым с "5 из 5", чтобы игрок реально выбирал, чью
сторону не держать.

### 3. Флот — "Судовладелец"
Метрика: количество одновременно активных капитанов на маршрутах.
Никакого жёсткого лимита в коде — вместо этого стоимость найма растёт экспоненциально с
каждым следующим капитаном (классический idle-паттерн), так что игрок естественно упирается
в потолок, комфортный именно его стилю:

- 1-й капитан: дешёвый, почти импульсивная покупка — обучающий момент "о, теперь есть кто-то
  ещё, кроме меня".
- 2-й: заметно дороже + требует репутации/подтверждённого послужного списка (например,
  открывается только после N успешных личных плаваний — предотвращает найм капитана раньше,
  чем игрок понял рынок сам).
- 3-й и далее: цена растёт кратно (например ×2.5-3 за каждого следующего) — не запрет, а
  естественный тормоз, чтобы 5-6 капитанов оставались осознанным поздним вложением, а не
  стартовой целью.

"Судовладелец" (потолок) = держать 4+ капитана одновременно — статистически редко для
казуального прохождения, реалистично для игрока, зашедшего в стадию 4.

## Капитан/автобой на маршруте (по итогам обсуждения)

- Единая модель угрозы с игроком: шанс атаки и шанс сбежать зависят от репутации с той же
  логикой, что описана для игрока (нейтральная репутация → враг обычно отступает после одной
  неудачной погони; низкая репутация → преследуют настойчивее).
- Бот-корабль (и NPC, и капитан игрока) пытается сбежать при низких шансах на победу, дерётся
  только когда деваться некуда — то есть один и тот же AI-модуль угрозы обслуживает и вражеские
  корабли, и корабли игрока под управлением капитана. Экономит разработку — не нужен отдельный
  движок для NPC vs NPC.
- Потеря корабля реальна (груз/корабль/возможно сам капитан) — это то, что реально заставляет
  игрока выбирать безопасные, но менее прибыльные маршруты для флота vs рискованные, где сам
  плывёт лично. Разница риска между "личным" и "делегированным" плаванием — это и есть та
  игровая механика, которая делает найм капитана осмысленным выбором, а не чистым апгрейдом.
- Никакого ручного боя за капитана — только лог/отчёт результата (сохраняет фокус на торговле
  как на центральной механике, бой NPC vs NPC не должен отвлекать интерфейсом).

## Что сознательно вырезано из скоупа оригинального Port Royale

- Вид города сверху и застройка — не будет вообще.
- Производственные цепочки сырьё → полуфабрикат → товар — заменены существующей живой
  supply/price моделью, без отдельного производственного слоя.
- Governor-квесты/полноценная городская администрация — Commandant's Office остаётся
  репутация + займы, не разрастается в отдельную квестовую систему.

## Открытые вопросы для следующего захода
- Точные числа: стартовое золото, цена каждого класса корабля, цена warehouse-апгрейдов —
  нужны для перевода относительных порогов выше в реальные цифры.
- Как именно repутация конфликтует между фракциями (симметрично? есть "вечные враги" пары?).
- Экономика найма капитана: разовая цена или цена + периодическое жалование (второе сильнее
  давит на "не нанимай больше, чем можешь себе позволить содержать").
