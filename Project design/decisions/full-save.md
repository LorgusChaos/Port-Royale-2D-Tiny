# Полный сейв — лист решений (принят автором 2026-11-14 без правок)

Повод: пересмотр решения по находке 12 ревью — «сейв должен быть полноценный и игра продолжаться
полностью с тех же событий, на которых она была сохранена». Удалить этот файл, когда работа
выйдет в релиз.

## Правила
1. После загрузки — тот же мир: каждый корабль ИИ на своём месте, с флагом, классом, корпусом,
   курсом и делом (рейс, патруль, крейсерство, погоня, бегство). Полное состояние `AiShip`;
   ссылки между кораблями — по `id`. *Иначе:* только позиции и роли. `[форма]` — новый раздел
   сейва «мир».
2. Рейд — с той же стадии и таймером: отряд, точка сбора, метки, эскадры, объявлен ли, отправлен
   ли ответ; эскалация флотов, время до следующего рейда. *Иначе:* отменять рейд. `[форма]`
3. Морские события — те же места, вид, таймеры. *Иначе:* раскладывать заново. `[форма]`
4. Корабль игрока продолжает: курс автопилота с портом назначения, охота, направление носа.
   *Иначе:* только позиция. `[форма]`
5. Капитаны продолжают манёвры: путь обхода/укрытия (`fleetPaths`) и угроза. *Иначе:*
   пересчитывать. `[форма]`
6. Счётчик номеров кораблей сохраняется. `[константа]`

## Числа
7. Сейв ~60–100 КБ; атомарная запись остаётся. `[константа]`
8. Версия раздела «мир» — 1; незнакомая версия → мир заново. `[константа]`

## Краевые случаи
9. Старый сейв без раздела «мир» — как сейчас: новый мир. *Иначе:* отказ. `[форма]`
10. Битые ссылки обнуляются; рейд без живых пиратов кончается молча. `[константа]`
11. Бой не сохраняется (находка 14); окно «Fight / Sail On» не сохраняется — встреча
    предложится снова. `[константа]`
12. Мир восстанавливается точно; будущие броски `GameRandom` не обязаны повторять несохранённую
    игру. *Иначе:* сериализовать состояние генератора. `[форма]`
13. Сторож и бюджет маршрутов не сохраняются. `[константа]`

## Место в UI
14. Новых экранов нет; при старом сейве — тост «мир создан заново». `[константа]`

## Не делать
15. Бой, очередь сообщений, камера. 16. Остальной формат сейва и сериализатор не менять.

## Готово когда
17. Тесты: мир → JSON → мир равен исходному (корабли с полями и ссылками, рейд, события, корабль
    игрока); старый сейв → новый мир; битые ссылки обнуляются; восстановленный мир делает тот же
    следующий шаг, что исходный.
18. Автор: сохранить во время объявленного рейда с погоней и сундуком рядом → выйти → загрузить:
    всё на тех же местах и продолжается.
